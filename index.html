What is "ASCII"?

ASCII, American Standard Code for Information Interchange, is a computer code that assigns a numerical value to basic English letters, characters, and symbols. It can be though of a bridge from human readable text that connects to the binary language of computers.

An example of this is the capital letter 'A' is represented by the decimal value 65; For our binary people out there it would be 01000001.
